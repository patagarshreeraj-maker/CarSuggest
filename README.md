# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/eab0b992-56ed-4185-826c-5981c8a4f2fb

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

## Car Lineup & Images

`src/data/cars.ts` exports `CARS_DATASET` — 215 models covering every major brand
sold in India (Maruti Suzuki, Hyundai, Tata, Mahindra, Toyota, Kia, BMW,
Mercedes-Benz, Porsche, Ferrari, Rolls-Royce and more). The 27 flagship models
have hand-curated specs and locally bundled photos; the rest are generated by
`scripts/build-car-lineup.mjs` with indicative Indian-market prices and specs.

Most model photos are hotlinked Wikimedia Commons thumbnails (Wikimedia
permits hotlinking; source pages are recorded in `src/data/imageAttribution.ts`
for attribution). A few brand-new models with no Commons photos yet fall back
to the built-in branded silhouette.

To refresh the lineup: `node scripts/build-car-lineup.mjs` (uses the cached
image URLs in `scripts/image-cache.json`; pass `--local` to download images
into `src/assets/images` instead of hotlinking).
